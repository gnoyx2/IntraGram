# Code of Conduct

IntraGram's issues, pull requests and discussions are for building the app.
Be kind and specific, assume good intent, and keep criticism about the work,
not the person.

Not acceptable: harassment, insults, discriminatory language or imagery,
sexualized content, threats, publishing someone's private information, and
sustained disruption of a discussion.

Maintainers may edit or remove comments, close threads and block accounts that
break these rules. Report a problem privately to the maintainers through the
contact in `SECURITY.md`; reports are kept confidential.

This code is adapted from the Contributor Covenant, version 2.1
(https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
